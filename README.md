# 花の勝率カウンター（OBS用）

花をモチーフにした勝率カウンターです。**操作パネル**と**カウンター**が別々のページになっています。

- テーマ: 桜 / 薔薇 / 桔梗 / 向日葵 / 紫陽花
- 形: 花のリース（円形）/ 花のつる（横長）
- 勝率10%ごとに花がひとつ咲きます。勝つと花びらが舞い、負けると少し散ります。

```
public/          ← Cloudflare に置くファイル一式
  index.html     案内ページ
  control.html   操作パネル（OBSのドック用）
  counter.html   カウンター（OBSのブラウザソース用）
  flowers.js / theme.css
lua/obs-winrate.lua   （別案）テキストソース用のOBSスクリプト
```

## 1. Cloudflare に置く

Cloudflare Pages に `public` フォルダをアップロードします（Git連携なら、出力ディレクトリに `public` を指定）。
公開後は `https://<プロジェクト名>.pages.dev/` で開けます。

## 2. OBS の設定

1. **ツール → WebSocketサーバー設定**: 「WebSocketサーバーを有効にする」をオンにする。パスワードは「接続情報を表示」で確認できる
2. **ドック → カスタムブラウザドック**: URL に `https://<プロジェクト名>.pages.dev/control` を追加する
3. 追加したドック（操作パネル）の「OBS接続設定」にパスワードを入力し、「保存して接続」を押す。右上に「OBS接続中」と出ればOK
4. 操作パネルの「カウンターのURLを作成」で、花・形・大きさを選んでURLをコピーする
5. OBS で **ブラウザ** ソースを追加し、コピーしたURLと、パネルに表示される推奨サイズ（幅・高さ）を入力する

操作: 勝ち +1 / 負け +1 / 取り消し / リセット（誤操作防止のため2回押し）。パネルにフォーカスがあるときは `W` `L` `Z` キーでも操作できます。

## 仕組み

操作パネルは OBS の WebSocket（`127.0.0.1:4455`）に接続し、
obs-browser の `emit_event` を使ってブラウザソースへ値を送ります。サーバーは不要です。

- 勝敗の数値は操作パネル側に保存されます。カウンターも最後に受け取った値を覚えているので、OBSを再起動しても残ります。
- 操作パネルは1か所（OBSのドック）で使ってください。普通のブラウザで開いた場合は、別の保存場所になります。
- 普通のブラウザ（Chrome など）で操作パネルを開くと、「ローカルネットワークへのアクセス」の許可を求められることがあります。

## URL パラメータ（カウンター）

| パラメータ | 例 | 内容 |
|---|---|---|
| `theme` | `sakura` `rose` `kikyo` `sunflower` `hydrangea` | 花の種類 |
| `layout` | `line` | 横長（省略時は円形） |
| `scale` | `1.5` | 大きさの倍率 |
| `decimals` | `0` | 勝率の小数桁（省略時は1） |
| `petals` | `0` | 花びらの演出を止める |
| `card` | `0` | 背景プレートを消す |
| `id` | `rank` | 複数のカウンターを使い分ける（操作パネルの URL にも同じ `?id=` を付ける） |

## 別案: Lua スクリプト（`lua/obs-winrate.lua`）

テキストソースに「12勝 8敗 勝率 60.0%」のような文字を表示するシンプル版です。OBS のホットキーで操作するため、ゲーム中でもキーが効きます。
**ツール → スクリプト** で読み込み、テキストソースを選んでから、**設定 → ホットキー** の「勝率: 〜」にキーを割り当ててください。
