# OBS 勝率カウンター

2種類あります。用途に合わせてどちらか一方を使ってください。

| | ① Luaスクリプト（おすすめ） | ② ブラウザソース（Web） |
|---|---|---|
| 操作 | OBSのホットキー（**ゲーム中でも効く**） | OBSの「対話」画面でクリック / キー |
| 見た目 | テキストソースの設定で自由に変更 | 色付き・勝率バー付き |

## ① Luaスクリプト `obs-winrate.lua`

1. OBSで **テキスト (GDI+)** ソースを追加（名前は例: `勝率`）
2. **ツール > スクリプト > ＋** で `obs-winrate.lua` を追加
3. 右側で「テキストソース」に 1 のソースを選ぶ
4. **設定 > ホットキー** の「勝率: 勝ち +1 / 負け +1 / 取り消し / リセット」にキーを割り当て

表示形式の置き換え文字: `{W}` 勝ち / `{L}` 負け / `{T}` 試合数 / `{R}` 勝率  
例: `{W}勝 {L}敗  勝率 {R}%`（改行も可）。数値はスクリプト画面から直接修正もできます。

## ② ブラウザソース `overlay.html`

1. OBSで **ブラウザ** ソースを追加
2. 「ローカルファイル」にチェックして `overlay.html` を選択（または GitHub Pages 等で公開した URL を指定）
3. ソースを右クリック > **対話** を開き、マウスを乗せると操作ボタンが出ます  
   キー操作: `W` 勝ち / `L` 負け / `Z` 取り消し（リセットはボタンを2回押し）

URLパラメータで見た目を変更できます（ローカルファイル時は URL 欄に直接指定）:

| パラメータ | 例 | 内容 |
|---|---|---|
| `size` | `size=64` | 文字サイズ(px) |
| `color` / `win` / `loss` | `win=00ff88` | 文字色 / 勝ち数の色 / 負け数の色 |
| `bar` | `bar=1` | 勝率バーを表示 |
| `decimals` | `decimals=0` | 勝率の小数桁 |
| `id` | `id=rank` | 別カウンターとして保存（複数設置用） |
| `panel` | `panel=1` | 操作ボタンを常に表示 |

例: `overlay.html?size=60&bar=1&decimals=0`

数値はブラウザ内に保存され、OBSを再起動しても残ります。
